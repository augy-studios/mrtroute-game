# css

- `theme.css`: the uwuapps theme system, verbatim from `uwuapps-theme.md`
  section 1, time-based mode included. Change it only when that spec changes.
- `style.css`: layout and components for this app, including the update bar
  and the line guide. Colours come from theme tokens only; line colours come
  from the data as `--line` and only draw rails and dots, never text.
